# Правила формирования отчёта «Личный состав»

Документ закрепляет прикладной порядок формирования отчёта. Он не изменяет кадровые данные, справочники или структуру базы данных.

## Источник и охват

Отчёт строится только по действующим сотрудникам, активным лицам и их текущим активным первичным назначениям из оперативного кадрового контура. Импортные строки, кандидаты, архивные сотрудники и исторические либо непервичные назначения не используются.

Пользователь может сформировать отчёт по всем доступным отделениям, выбранной группе или одному отделению. Во всех вариантах применяются действующие ограничения организационной видимости.

## Порядок групп и отделений

Группы следуют устойчивому порядку справочника `deps_group` по `group_id`:

1. Клинические (`group_id = 1`).
2. Параклинические (`group_id = 2`).
3. Административно-хозяйственные (`group_id = 3`).

Внутри группы отделения сортируются по наименованию. Отделения без действующих сотрудников в отчётную сводку и подробную часть не включаются.

## Должностные ранги

Для клинических и параклинических отделений действует порядок:

1. Заведующий отделением.
2. Врачи.
3. Старшая медицинская сестра или старший медицинский брат.
4. Остальные медицинские сёстры и медицинские братья.
5. Сестра-хозяйка.
6. Санитарки и санитары.
7. Прочие должности.

Более конкретные признаки проверяются раньше общих. Признак заведующего имеет приоритет перед врачебным; старшая медицинская сестра не относится к обычным медицинским сёстрам; сестра-хозяйка имеет самостоятельный ранг. Неизвестная или отсутствующая должность относится к рангу «Прочие» и не прерывает формирование отчёта.

Для административно-хозяйственных отделений сначала выводятся руководители, затем остальные сотрудники. Руководитель определяется по структурированному признаку справочника должностей `positions.category = 'leaders'`; распределённые строковые проверки для этого не применяются.

Внутри каждого ранга сотрудники сортируются по ФИО. Нумерация начинается заново в каждом отделении.

## Нормализация названий должностей

Перед распознаванием медицинского ранга название должности приводится к нижнему регистру, `ё` заменяется на `е`, разные виды дефисов заменяются пробелами, лишняя пунктуация и повторные пробелы удаляются. Правила учитывают мужские и женские формы должностей.

## Численность и ставки

Сводная таблица и подробная часть строятся из одного набора уникальных сотрудников по `employee_id`.

- «Количество человек» — число уникальных сотрудников отделения.
- «Количество ставок» — точная сумма `person_assignments.rate` тех же активных первичных назначений.
- Дробные ставки суммируются как десятичные значения без подстановки ставки по умолчанию.
- Сотрудник без ставки учитывается в количестве людей, но не увеличивает сумму ставок.
- При отсутствии ставки показывается примечание «Ставка не указана у N сотрудников».
- Итоговая строка содержит уникальную общую численность и общую сумму ставок выбранного охвата.

В Excel существующие ставки сохраняются числовыми ячейками с форматом `0.##`; отсутствующая ставка отображается текстом «Не указано».

## Единообразие представлений

Порядок групп, отделений и сотрудников, сводные показатели и подробные строки определяются backend-сервисом `build_personnel_roster`. Предварительный просмотр не пересортировывает данные. Excel формируется из того же структурированного результата, поэтому порядок сотрудников и итоги в обоих представлениях должны совпадать.
