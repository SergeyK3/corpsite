## Три кадровые выгрузки

Запросы выполнялись с настоящим API под помощником, HR_HEAD и DOCUMENTATION_VIEWER. Для помощника действуют `ASSISTANT_HR_EXPORT`, `ASSISTANT_HR_SUPPORT` и `CONTROL_LIST_EXPORT`. Для всех трёх выгрузок проверка прав помощника пройдена; ошибки ниже возникают в бизнес-обработчиках. HR_HEAD получает те же результаты. DOCUMENTATION_VIEWER получает 403.

| Выгрузка | Права помощника | Наблюдаемый ответ | Данные и совместимость |
| --- | --- | --- | --- |
| Контрольный список | Достаточны | 409 `CONTROL_LIST_ASSIGNMENT_CONFLICT` | `MISSING_PRIMARY_ASSIGNMENT`: нарушен инвариант активного основного назначения. Это блокировка данных, а не отказ разрешения; XLSX не сформирован |
| Канонический снимок | Достаточны | 404 `no active canonical snapshot for source_type=HR_CONTROL_LIST` | В тестовой БД нет снимков и опубликованных baseline. Дополнительно подтверждена несовместимость старого экспортера с текущей схемой: диагностический GET с `snapshot_id=1` возвращает 500 из-за отсутствующего `version` ещё при разборе SQL; это не существующий опубликованный снимок |
| Журнал кадровых изменений | Достаточны | 500 `UndefinedColumn: ps.version` | SQL экспортера обращается к отсутствующим `ps.version` и `ns.version`. Ошибка совместимости схемы возникает даже при пустом журнале; отсутствие событий не объясняет этот 500 |

Текущая `hr_canonical_snapshots` содержит `snapshot_id`, `source_batch_id`, `source_type`, `entry_count`, `promoted_by`, `promoted_at`, `publication_origin_id`, `report_period`, `deleted_at`; полей `version` и `status` нет. Старый экспорт канонического снимка требует оба поля, а также `snapshot['version']` для имени файла. Текущий `get_active_snapshot()` возвращает данные baseline без `version/status` и использует `baseline_id`; перед переносом экспортера необходимо согласовать также идентификаторы и источник строк. Одна публикация данных не доказывает исправность этой выгрузки.

Проверки конфликтов назначений не отключались. Кадровые данные, назначения, снимки, baseline и журнал не исправлялись ради выгрузок: до и после диагностики совпали количества и контрольные суммы строк этих таблиц. Служебный аудит выполнялся штатно.
