# Начальный двуязычный словарь подразделений из кадровых приказов

Статус документа: аналитический начальный словарь, не нормативный справочник.

## Метод и границы

Проверены текущие записи `org_units` локальной БД (поля: `unit_id`, `name`,
`name_ru`, `name_en`, `code` и служебные поля) и 50 читаемых DOCX: 47 файлов
архива `2026 ПРИКАЗ` и три проверенных вспомогательных DOCX. В архиве также
найдены два временных файла Word (`~$...docx`), не являющиеся читаемыми DOCX.

Количество упоминаний — число точных вхождений варианта в прочитанных текстах;
это не число сотрудников и не число приказов. В строке может быть несколько
орфографических вариантов одной кандидатной сущности. ID указан только при
прямом и достаточно сильном подтверждении; отсутствие ID намеренно не
означает создание новой записи.

В текущем справочнике почти все названия заданы по-русски в `name`, а `name_ru`
в основном пуст. Поэтому совпадение ядра названия само по себе не считалось
достаточным для привязки к `unit_id`.

## Неоднозначности и несопоставленные варианты

- `А блогы` в приказе №104 приведён вместе с мейіргері. Он не внесён как
  подразделение: по доступному тексту это блок/внутренний контекст, а не
  подтверждённое самостоятельное название. В `org_units` записи «А блогы» нет.
- `Терапия және паллиативтік көмек бөлімшесі` — историческое объединённое
  название. В действующем Excel-справочнике оно соответствует двум разным
  активным подразделениям: Паллиатив (48, `PALL`) и Терапия (51, `THER`),
  поэтому ID не назначен.
- Не присваивались ID строкам, где русский вариант лишь похож на текущий
  справочник: это защищает от ошибочного объединения отдела, отделения,
  центра, кабинета и секции.

- Уникальных вариантов названий, внесённых в начальную выборку: **33**.
- Строк: **25**; `CONFIRMED` — **9**, `PROPOSED` — **4**,

  (`REQUIRES_REVIEW` + `SOURCE_ONLY_*`) — **12**.

  Непрочитаны: `2026 ПРИКАЗ/АУЫСТЫРУ/~$стыру февраль.docx` и
  `2026 ПРИКАЗ/АУЫСТЫРУ/~$ЫСТЫРУ январь.docx` — временные Word-файлы,
  `BadZipFile`. Файлов формата DOC в указанном архиве не найдено.
