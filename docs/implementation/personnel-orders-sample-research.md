# Исследование образцов кадровых приказов

Дата исследования: 2026-09-13. Исходные каталоги читались без изменений.

## Состав

| Каталог | Формат | Файлов | Страниц PDF |
| --- | ---: | ---: | ---: |
| `Журнал кадровых приказов` | PDF | 6 | 137 |
| `2026 ПРИКАЗ Прием` | DOCX | 42 | — |

Все шесть PDF не имеют извлекаемого текстового слоя: это сканы, для извлечения
реквизитов нужен локальный OCR. На рабочей станции обнаружен Tesseract вне
`PATH`: `C:\Program Files\Tesseract-OCR\tesseract.exe`; доступны только
`rus`, `eng`, `osd`, а пакет `kaz` отсутствует. CLI автоматически находит этот
binary и использует `rus+eng`; документы с нераспознанными казахскими
фрагментами остаются для ручной проверки. DOCX корректно читаются локальной библиотекой
`python-docx`. Ни один документ не отправлялся в сеть.

## Подтверждённые ограничения

* Простое совпадение имени файла не является доказательством связи PDF и DOCX.
  Внешний инструмент сопоставляет их только по одновременно совпавшим
  нормализованным номеру и дате; несколько кандидатов — `DocumentConflicts`.
* До локального OCR номер и дата скана не считаются известными. Такая строка
  остаётся `REVIEW_REQUIRED`, не получает догаданный реквизит и не связывается
  с сотрудником.
* DOCX-папка содержит 42 файла, PDF-архив — 6 файлов; это не набор пар «один к
  одному». В частности, один приказ может требовать нескольких строк
  сотрудников, а часть DOCX не имеет предоставленного PDF-аналога.
* Автоматическое сопоставление сотрудника по ФИО запрещено. Даже точное ФИО из
  DOCX используется только как кандидат; импорт принимает только
  `employee_id` плюс контрольное ФИО из выгрузки Corpsite.

## Ограничение выборки

Проверен весь предоставленный набор по типам, количеству и текстовому слою.
Содержательное чтение реквизитов PDF требует работоспособного локального
Tesseract OCR и должно быть повторено оператором с сохранением диагностики.
Поэтому варианты рукописных исправлений, печатей, ориентации и конкретные
варианты номера/даты пока не объявляются подтверждёнными фактами.
